# CollabCampus – College Collaboration and Team Formation System

CollabCampus is a Python-based desktop application designed to simplify team formation and project collaboration among college students. It provides a centralized platform where students can discover teammates based on technical skills, create and join projects, manage tasks, and receive project notifications.

The system features student profiles, a project marketplace, dedicated project workspaces, an AI assistant for project-related queries, and a faculty dashboard for monitoring student projects. Built using **Python, CustomTkinter, and MySQL**, CollabCampus aims to make academic collaboration more organized, efficient, and accessible.

### Key Features

* Skill-based teammate discovery
* Project creation and marketplace
* Team collaboration and task management
* Project notifications
* Integrated AI assistant
* Separate student and faculty dashboards
* Secure authentication and database management

### Tech Stack

**Python | CustomTkinter | MySQL | bcrypt | python-dotenv**
